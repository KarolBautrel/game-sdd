# Drawn knight: static appearance pilot

User authorization 2026-11-03 resumes presentation019 with actual asset creation:
one knight, detailed pixel art and painted 2D proposals. Git history is deferred.
This owner supersedes research019's production prohibition for this static pilot.

Both proposals depict the same original knight, full body, three-quarter facing
screen right, with the existing shallow oblique camera (18 degrees). Natural
adult proportions, relaxed straight legs beneath the hips, proportional boots,
readable uncovered face, articulated armor and gloves are required. Use the
accepted environment's restrained earth/olive, navy, worn steel and brass palette.
Previous3D sources are reference/archive only; no Blender production is resumed.

Produce an independently layered rigid sword with an explicit grip point. Keep
the hand over the grip when assembled. Preserve the detached sword for future
pose work; a static layer separation does not prove animation readiness.

Use built-in imagegen for source drafts. Normalize/export through Aseprite,
preserving raw generated inputs, editable .aseprite sources, prompts and scripts.
Pixel output uses a native integer pixel grid, bounded palette, nearest scaling
and binary alpha; painted output retains smooth brushwork and edge alpha.
Compare both at 100px/metre (about171px projected standing height for1.8m at18deg)
and in a clearly labelled enlargement. Reuse actual current floor/prop textures;
label the board as a static composition, not a gameplay screenshot.

Scope is static appearance only. Selection belongs to the user. Animation,
eight directions, runtime roster changes and historical Git repair remain later
work. No desktop input, visible application launch, external provider purchase,
new tool installation, commit or push is needed for this pilot.
