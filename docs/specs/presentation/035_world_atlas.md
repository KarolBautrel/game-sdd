# World and province map interface

Date: 2026-11-04. Owners world009/002/003 and presentation029.

Preserve the accepted warm illustrated parchment, leather, brass, Cinzel and
Source Sans family. Use a coherent world chart and three new province plates
alongside the unchanged Marches artwork. Runtime controls own labels, current
position, roads, selection and travel; never bake interactive text into bitmaps.

The map header offers World / viewed province, Return to company location and
four province choices. World province markers open their map; browsing never
teleports or charges. Provincial landmarks are native focusable buttons with
name/type/current marker, selected state and trusted itinerary tooltip. Actual
roads connect authored anchors; the selected itinerary is highlighted. No labels
overlap or escape at720p/1080p; narrow layouts stack map and journey column.

The journey panel shows selected destination, province/description, ordered
stops, whole-plan hours/food and the NEXT leg's danger/arrival/cost/return reserve.
Confirm names the next stop. After arrival, the plan remains until its final
destination; events replace travel controls until resolved. Cancelling clears
only selection and returns focus to the destination. Browsing remote provinces
never changes the company location or its service availability.
Each confirmation is bound to its quoted origin and journey sequence; duplicate
activation of an old control cannot silently advance the next itinerary leg.
Town-bound multi-leg previews identify their provision-saving routing policy.

Mouse and keyboard activate the same native buttons. Browsing never writes a
save. Art uses built-in imagegen with the accepted map as reference and Aseprite
source/export. Retain prompts/provenance and reproducible editable sources.

Proof: slices/035_world_atlas.md, journey UI/atlas tests, native no-focus GPU/input
review at1280x720 and1920x1080. User visual approval/physical play remain pending.
