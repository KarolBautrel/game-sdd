Shared UI composition owns passive visual components, never gameplay decisions.

- `001_reusable_hud_components.md`: skinned frames, party cards and resource meters.
- `slices/001_reusable_hud_components.md`: stage3 acceptance proof.
- `002_campaign_interfaces.md` / `slices/002_campaign_interfaces.md`: stage19
  shared shell/theme, campaign navigation and responsive subviews.
- `003_visual_inventory.md` / `slices/003_visual_inventory.md`: stage20 icon
  inventory, portrait/slot editor, comparisons and retained selection.
- `004_service_interfaces.md` / `slices/004_service_interfaces.md`: stage21
  visual trade and training cards.
- `005_journey_interfaces.md` / `slices/005_journey_interfaces.md`: stage22 town
  service tiles and interactive region landmarks.
- `006_dark_fantasy_art_direction.md` / `slices/006_dark_fantasy_art_direction.md`:
  authorized stages23..26, coherent inventory art and illustrated parchment map.
- `007_expedition_combat_art_direction.md` / `slices/007_expedition_combat_art_direction.md`:
  authorized stages27..29, approved campaign family extended to dungeon and battle.
