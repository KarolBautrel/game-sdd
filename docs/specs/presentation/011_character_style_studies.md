# Isolated character style studies

Authorized2026-11-02: preserve/push the current rollback, research character art
skills and sources, then build several actual models for a user style choice.
This is a source-art experiment, not a new production roster replacement.

## Contract

Create three full 3D interpretations of the same veteran blue-cloaked sword and
round-shield mercenary: grounded painterly, angular graphic ink, and heroic
painted miniature. Change proportions, costume shape language and materials,
not just colour. Use a documented CC0 anatomical scaffold with modelled facial
forms/hands; clothing, hair, armour and equipment are separate authored meshes.
Record the distinction between scaffold and original design work.

All studies stay under `assets_src/characters/style_studies/2026-11-02/` behind
the existing `.gdignore`. No production roster/sprite/material/domain files are
changed. The restored stage33 animation and stage36 world stay intact.

Each study includes its own Blender scene, FBX, portable baked albedo, matching
neutral orthographic front/side/back/three-quarter renders, face detail and an
exact100px/m tactical render. Keep identical lighting/exposure and camera recipes
for comparisons. Native-scale sprites must also be shown on retained world art.
Aseprite owns comparison assembly and editable raster source.

These are static visual studies. They do not claim working rigs, locomotion,
equipment swapping or gameplay acceptance. User selection precedes any separate
rigging/animation/integration task. Research must name primary sources, licenses,
what was actually used, and tools which remain optional/unconnected.
