# Slice015: MPFB warden static pilot

Owner presentation015. Acceptance scenarios:

1. Pinned official MPFB imports/registers in owned factory-startup Blender5.2.3;
   generate an actual human using documented API and load matching CC0 skin/eyes.
   Record origins, hashes and license files. No global preferences modified.
2. Actual saved source uses coherent skin UVs with separate eyes/hair; no old
   whole-body front/profile/back paint blend drives the skin. Material/image
   dependencies resolve after reopening, and visual UV-checker review is recorded.
3. Inspect face front/profile/three-quarter under neutral and changed light, and
   full-body views with retained warden costume. Reject doubled facial features,
   painted eyes/hair on skin, severe seams, clipping and waxy material response.
4. Export FBX and reopen in a fresh scene; verify actual meshes, bounds, UVs and
   texture dependencies and render the imported result. Save source and textures.
5. Aseprite review boards show the actual model, matched prior comparison and
   native100px/m ground composition, with no runtime/animation claim.
6. Verify exact prior source-delivery hashes and retained roster/world guard;
   project validator and git diff --check pass. Persist technical/art gaps and
   source identities in stage41 and milestone010. User visual acceptance remains
   pending; no animation or roster rollout starts this increment.

Proof scripts and exact evidence paths are recorded in the stage41 report.
Physical game cases are outside this static pilot and remain deferred.
