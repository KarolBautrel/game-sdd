# 020 Ranged Attacks

Status: planned  
Date: 2026-07-14

## Intent

Ranged attacks allow units to target enemies beyond adjacent melee range.

## Planned Scope

- ranged action data contract;
- minimum and maximum range;
- ammunition or cooldown policy;
- interaction with line of sight;
- interaction with cover;
- event log for ranged attacks.

## Deferred Until

- enemy AI v0 exists;
- round cycle is stable;
- victory condition is implemented;
- debug scene can show legal tiles and targets.

## Initial Questions

- Should ranged attacks have minimum range?
- Are ranged weapons grid-based only, or can skills target areas?
- Does ammo exist in the first vertical slice?
- Should ranged attacks provoke reaction attacks later?
