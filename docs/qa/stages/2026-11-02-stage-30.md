  Measured reference regions, corrected face/front/rear placement and mapped
  interior material patches; reviewed corrected front/side/rear output.
- Fourteen death views clipped the extended weapon on a256 canvas. Re-rendered
  the whole family on448x352 with one pivot; all256 margins now pass.
- Legacy width-based corpse selection chose an early frame on fixed canvases.
  Original raider now holds its authored final death frame.

  rates now reach every terminal action frame inside actual resolver presentation;
  legacy timing remains covered by regression.

  Added source-only .gdignore; runtime uses exported PNGs. Two catalogue-count
  assertions were updated for the new registered scenario.

  the proof to the same imported-resource image reader used by runtime; zero
  warnings on the final run.
- The release preparer previously rewrote only dungeon preview profiles. It now
  normalizes any owned source main-scene entry to App in the release alone;
  actual release metadata/profile and unchanged source hash were checked.
