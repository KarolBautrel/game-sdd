This directory retains portable automated evidence for the opt-in campaignv3.
The governing rules are world018 and presentation045; QA and handoff navigation
are in docs/qa/2026-11-09-strategic-region.md and its matching handoff.

The first full run failed one check because malformed boolean versions reached
a numeric comparison in new format dispatch. `first-run.*` records that failure.
It is not acceptance. The corrected final2 report/streams and source integrity
are separate. No physical gameplay, visible launch or animation review is claimed.

The normal-command trace records a headless managed mine battle. It uses real
resolver legality, both sides' commands, pending-combat persistence, loot, exit
and settlement; no Debug Win. Save/art hashes are preservation evidence only.
Individual path-query timings are not FPS measurements.
