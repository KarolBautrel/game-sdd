# Repeatable campaign UI workflow

Read presentation006 and slice006 before changing campaign UI. The selected
inventory target is concept A in README.md; use actual native GPU captures to
compare changes. Game legality stays in CampaignSession/domain commands.

Installed Codex skills: game-ui-ux and godot-ui-control from
gamedev-skills/awesome-gamedev-agent-skills, installed under
C:/Users/karol/.codex/skills. Read their SKILL.md when working on these interfaces;
also follow the existing godot-gamedev and create-game-assets skills. A fresh
Codex turn discovers new skills and the configured godot-ui MCP. No desktop input
is authorized while the user uses the PC.

Godot MCP lives at C:/Users/karol/.codex/tools/godot-mcp, upstream
Vollkorn-Games/godot-mcp commit632530638448ea3e79394fbf74e9a5c92c4b67e5.
The installed server's75-tool protocol/version check is repeatable with
`.venv/Scripts/python.exe tools/qa/probe_godot_mcp.py`.

Asset dependencies and pinned hashes: tools/assets/ui_dependencies.json.
Fetch/restore with tools/assets/fetch_ui_dependencies.ps1. Full packs stay in
assets_src/vendor, outside runtime import/export. Selected assets pass through
tools/assets/build_campaign_ui.ps1 (Aseprite); generated originals and production
specifications stay in assets_src/campaign_ui. Rebuild the PNG catalogue using
`.venv/Scripts/python.exe tools/assets/build_catalogue.py`.

Base Theme is generated by ThemeGen via tools/ui/build_campaign_theme.ps1,
using a headless editor plugin. The project subclass frees ThemeGen1.4 temporary
Control probes; the pinned vendor file is unchanged. Runtime uses a plain Theme
resource plus CampaignSkin state styling; editor addons are excluded from PCK.

Automated native review (minimized, no_focus, isolated in-memory save, real GPU):
`.venv/Scripts/python.exe tools/qa/render_campaign.py --run-id UNIQUE --views region,town,stash,trade,training --sizes 1920x1080,2560x1440,1280x720 --exercise`

Use --exe with the final release executable to test its packaged resources.
Inspect PNGs and native-review.json, fix defects and repeat affected scenarios.
This engine-local pointer fixture does not replace actual desktop keyboard,
hover/focus feel or normal gameplay. Keep deferred cases in live-test-scenarios.md.

After export_smoke.py succeeds, prepare its local UI launch profile and complete
notices with `.venv/Scripts/python.exe tools/qa/prepare_ui_release.py artifacts/export-smoke/RUN_ID`.
This validates EXE/PCK hashes, writes the owned release-only App window profile
and leaves the source profile intact. The final build is recorded in stage26 report.
