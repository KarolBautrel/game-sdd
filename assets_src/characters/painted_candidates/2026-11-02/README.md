# Three painted static3D candidates

Open `comparison.png` first, then `before_after.png` and `all_views.png`.
These are actual Blender renders. `*/concept.png` files are original generated
design references, separately labelled; they are not model evidence.

I: leather mercenary. II: steel warden. III: long-coat wayfarer.
Each folder contains editable .blend/source parts, static FBX,2048px albedo,
Ucupaint paint workspace, multi-view renders and geometry-only review.
The three boards have editable Aseprite sources.

No rig, animation or runtime replacement. Production roster/world are retained.
Some projected texture seams and inferred geometry remain; choose a direction
before a rigged pilot. No desktop input or visible editor/game launch occurred.
