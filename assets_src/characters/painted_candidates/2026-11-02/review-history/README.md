# Rejected first pass

`brightness-key-*` are actual model renders of the rejected brightness-based
background key. It incorrectly removed pale skin/metal paint and missed backdrop
at poorly fitted UV edges. Final sources use an Aseprite connected-background
matte, paint padding and per-part silhouette mapping.

`trouser-clipping-fbx.png` is the rejected fresh FBX render with a small triangular
trouser breakthrough on the left coat panel. The covered upper trousers were
conformed inside the garment envelope, then all models/export checks rebuilt.

These are failure evidence, not current proposals. Temporary collar/neck
experiments were also rejected and rebuilt; see the stage39 report.
