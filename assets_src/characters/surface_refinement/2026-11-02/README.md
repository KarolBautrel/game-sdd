# Less angular painted candidates

Open `comparison.png` for all3 before/after pairs. `details.png` shows the warden
bust at original resolution; `all_views.png` shows new front/profile/rear coverage.
The boards have editable Aseprite sources. These are actual Blender model renders;
native floor panels are reference composites, not gameplay screenshots.

Each model has a .blend, static FBX,2048px albedo, separated authoring parts and
editable Ucupaint image layer. No rig, animation or runtime integration. Original
stage39 sources remain unchanged in `painted_candidates/2026-11-02/`.

See [production guide](../../../../docs/design/character-art/SURFACE_REFINEMENT.md),
[stage40](../../../../docs/qa/stages/2026-11-02-stage-40.md), `verification.json`,
`provenance.json`, `delivery.json` and each `model.json` for proof and limitations.
